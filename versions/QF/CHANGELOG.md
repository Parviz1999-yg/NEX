# QF — Qiziqarli fakt o‘zgarishlar tarixi

## [0.11.0] — 2026-11-22

- Three.js asosidagi haqiqiy WebGL 3D sahna dvigateli ulandi.
- Fan sohasi bo‘yicha alohida boshlang‘ich 3D kompozitsiyalar qo‘shildi: fizika, biologiya, tarix, matematika, astronomiya, kimyo, geografiya, texnologiya va psixologiya.
- Sahna o‘lchami oynaga moslashadi; animatsiya avtomatik ishlaydi.
- 3D kutubxonasi CDN orqali dinamik yuklanadi; yuklanish xatosi interfeysda ko‘rsatiladi.
- Fakt ssenariysi generatoriga manba havolasi formatini tekshirish qo‘shildi.
- Bu bosqich hali fakt matnidan semantik 3D sahna yaratmaydi; obyektlar fan sohasi bo‘yicha bazaviy vizual prototiplardir.
- Mobil WebGL va GitHub Pages jonli brauzer sinovi hali bajarilishi kerak.

## [0.10.0] — 2026-11-22 (boshlang‘ich qayd)

- Mustaqil QF modulining boshlang‘ich versiyasi.
- Ushbu boshlang‘ich qayd oldingi umumiy CHANGELOG tarixidan ko‘chirilgan to‘liq modul tarixini anglatmaydi; keyingi modulga tegishli o‘zgarishlar shu faylda alohida qayd etiladi.
